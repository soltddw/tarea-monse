01. Introducción

En este sitio web se presenta un análisis exhaustivo y argumentado a partir del material audiovisual estudiado. La propuesta abarca la definición de pilares fundamentales en programación web, la resolución del cuestionario académico con lenguaje técnico propio y la demostración práctica del flujo de trabajo necesario para llevar una aplicación desde el código fuente hasta un servidor en línea accesible a todo público.

02. Conceptos Fundamentales

Etiquetado Semántico

Organización lógica del código HTML5 mediante bloques definidos para mejorar la accesibilidad y el SEO.

Cascada de Estilos (CSS)

Mecanismo de jerarquía y aplicación de reglas visuales para personalizar componentes web.

Control de Versiones

Gestión del historial de cambios de un proyecto utilizando repositorios remotos en GitHub.

Servicios de Hosting

Infraestructura en la nube (como Render) encargada de procesar y servir sitios web a los usuarios.

Adaptabilidad (Responsive)

Diseño flexible orientado a ajustar dinámicamente la disposición de los elementos a cualquier pantalla.

03. Cuestionario Resuelto

Q1

¿Cuál es el tema principal del video? Explica de qué trata.

El tema central es la creación y publicación de plataformas web modernas. Explica detalladamente cómo transformar maquetas e ideas de código en aplicaciones estáticas funcionales, listas para ser desplegadas en la red mundial de forma profesional.

Q2

¿Qué problema o necesidad tecnológica se aborda?

Aborda la problemática de la incomunicación entre el desarrollo local y el entorno en vivo, enseñando a resolver fallas frecuentes de configuración y eliminando la dependencia de servidores pagados o complejos para publicar proyectos web.

Q3

¿Cuáles son los cinco conceptos más importantes? Define cada uno.

1. Maquetación: Proceso de ordenamiento y jerarquización del contenido mediante etiquetas HTML.
2. Estilizado: Personalización de la apariencia visual (colores, fuentes y espacios) mediante hojas CSS.
3. Commit: Registro o guardado oficial de una versión modificada del código en GitHub.
4. Alojamiento Estático: Almacenamiento de archivos listos para el consumo del usuario sin bases de datos dinámicas intermedias.
5. URL Pública: Dominio web único generado para permitir la navegación abierta en internet.

Q4

¿Qué herramientas, programas o tecnologías se mencionan y para qué sirven?

Se destaca el uso de Visual Studio Code para estructurar los archivos fuente, GitHub como plataforma colaborativa y de control de versiones, y Render como la nube encargada de transformar el repositorio en un sitio ejecutable.

Q5

¿Qué procedimientos o pasos se explican? Preséntalos en orden.

1. Estructurar y guardar los archivos correspondientes a `index.html` y `estilos.css`.
2. Abrir una cuenta e iniciar sesión en la plataforma GitHub.
3. Crear un repositorio público dedicado al proyecto.
4. Cargar los archivos fuente mediante la función de subida en la interfaz de GitHub.
5. Conectar el repositorio con la cuenta de Render para generar la compilación y obtener el enlace público.

Q6

¿Qué ejemplos prácticos aparecen? Explica uno detalladamente.

Se ejemplifica el despliegue automático continuo: al asociar el repositorio de GitHub con Render, este último detecta cualquier actualización guardada (commit) y reestructura automáticamente la página pública sin necesidad de volver a subir el sitio de forma manual.

Q7

¿Qué conocimientos previos son necesarios para comprender lo explicado?

Fundamentos básicos de informática, comprensión sobre la jerarquía de directorios en un equipo, lógica básica de marcado web e interacción con plataformas en la nube.

Q8

¿Qué ventajas o beneficios ofrece la tecnología o procedimiento?

Aporta autonomía al estudiante o desarrollador para publicar sus trabajos en tiempo real, brinda acceso global inmediato a través de enlaces compartibles y optimiza los recursos al utilizar tecnologías web ligeras e intuitivas.

Q9

¿Qué dificultades, errores o precauciones deben considerarse?

Es indispensable verificar la exacta concordancia entre los nombres de los archivos en el código y en la carpeta, asegurarse de que la privacidad del repositorio esté configurada como **Pública** y testear la URL final en ventanas de incógnito.

Q10

¿Cómo aplicarías lo aprendido en un proyecto informático real?

Construyendo el portafolio profesional personal, maquetando la página institucional para una empresa o publicando tableros frontend vinculados a bases de datos en la nube.

Q11

¿Qué parte del video consideras más importante y por qué?

El segmento dedicado a la vinculación y publicación en Render, dado que es el punto exacto donde el código abstracto local cobra vida y se convierte en una herramienta funcional en la web real.

Q12

¿Qué conocimientos nuevos adquiriste y cómo los explicarías a otra persona?

Aprendí el circuito de publicación con servicios de nube estáticos. Lo explicaría haciendo una analogía: redactar el código es escribir un libro, subirlo a GitHub es llevarlo a una imprenta pública y desplegarlo en Render es colocarlo en la vitrina de la librería para que todos lo puedan leer.
